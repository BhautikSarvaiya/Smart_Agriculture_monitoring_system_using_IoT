# Smart_Agriculture_monitoring_system_using_IoT
I successfully designed and developed an IoT-Based Smart Agriculture Monitoring and Irrigation System using the ESP32 DevKit V1 as part of my embedded systems and IoT learning.

The system monitors temperature, humidity, and soil moisture in real time using a DHT22 sensor and a simulated soil moisture sensor. Based on the soil moisture level, it automatically controls irrigation through a relay module, while an OLED display provides local monitoring of sensor readings and pump status.

The ESP32 transmits telemetry data to the ThingsBoard IoT platform using the MQTT protocol over Wi-Fi, enabling real-time cloud monitoring and visualization through an interactive dashboard. The complete project was designed, programmed, and tested using the Wokwi online simulation platform and Arduino IDE.

🔹 Key Features
Real-time temperature and humidity monitoring
Soil moisture monitoring and automatic irrigation control
OLED display for live sensor data
Cloud-based monitoring using ThingsBoard
MQTT communication for IoT data transmission
Wi-Fi-enabled ESP32 connectivity
Wokwi-based circuit simulation and testing
